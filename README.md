# Manicure Gardening Services

San Jose landscaping, sprinklers, gardening, and lawn care site exported from Emergent.

- Public site + estimate form
- `/admin` owner inbox
- FastAPI + MongoDB backend
- Live domain: https://manicuregardenservices.com

The original Emergent project is unchanged.

## Free hosting

Deployed on Render (free web service) + MongoDB Atlas M0. Domain stays on Spaceship; Render provides HTTPS.

Required environment variables are listed in `backend/.env.example`.
